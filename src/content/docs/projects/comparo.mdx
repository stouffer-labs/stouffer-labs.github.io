> MCP server that orchestrates Claude Code, Codex CLI, and Gemini CLI for cross-validation.

[![GitHub](https://img.shields.io/badge/GitHub-stouffer--labs%2FComparo-blue?logo=github)](https://github.com/stouffer-labs/Comparo)

## Overview

Comparo runs independent AI CLI reviewers (Claude, Codex, Gemini) as background jobs to
cross-validate code and designs, then consolidates their findings into a single comparison.
It exposes this as MCP tools so any MCP-capable CLI can request an independent second opinion.

## Quick Start

```bash
curl -fsSL https://raw.githubusercontent.com/stouffer-labs/Comparo/main/scripts/install.sh | bash
comparo mcp setup
comparo doctor
```
