> Pass the baton between machines — a terminal menu to list and resume your
> claude and codex CLI sessions, grouped by project, with a live preview.

[![GitHub](https://img.shields.io/badge/GitHub-stouffer--labs%2Fbaton-blue?logo=github)](https://github.com/stouffer-labs/baton)

## Overview

Baton scans the session transcripts that Claude Code and Codex CLI already write to disk,
shows them in an fzf picker grouped by the directory each was started in, and resumes the
one you pick natively (`claude --resume` / `codex resume`). No tmux, no multiplexer — so
mouse selection, copy/paste, and scrolling stay fully native on macOS and Linux, locally
or over SSH. Start a session on one machine, then hand it off to another wherever you are.

## Quick Start

```bash
curl -fsSL https://raw.githubusercontent.com/stouffer-labs/baton/main/scripts/install.sh | bash
baton          # active sessions + the 10 most recent closed ones
baton --all    # every recent session
```
